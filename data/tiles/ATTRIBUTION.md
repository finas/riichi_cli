# Tile artwork attribution

The PNG tile artwork in this directory is derived from
[FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles)
by FluffyStuff. The upstream project dedicates these assets to the public
domain. The artwork has been resized and renamed to preserve MahjongCLI's
existing tile-ID filename mapping.
